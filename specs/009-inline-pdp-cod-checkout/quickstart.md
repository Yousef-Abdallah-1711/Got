# Quickstart: Inline Product-Page COD Checkout

1. Open a product page, select a valid size/color, click "Order now" → confirm the page scrolls to and focuses the inline form.
2. Fill in contact/delivery details, accept terms, submit → confirm an order is created, confirmation page/email match the standard checkout exactly.
3. Add unrelated items to your cart first, then place an inline order for a different product → confirm the cart's existing contents are completely unchanged afterward.
4. Double-click submit (or resubmit within the protection window) → confirm the same order is returned, not a duplicate, and stock is reduced only once.
5. Set the selected variation's stock to 0 → confirm the inline form is disabled with a clear message.
6. Enter an address in a governorate with no shipping zone → confirm the same "we do not deliver to this governorate yet" message as the standard checkout, and no order is created.
7. Compare an inline order's total against a standard-checkout order for the identical product/variation/quantity/address → confirm they match exactly.

**Done when**: all 7 steps pass.
