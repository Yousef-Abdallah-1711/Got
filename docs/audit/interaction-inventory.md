| Early-access email sign-up | `EarlyAccessForm` (used in `ComingSoon.jsx`) | Mock — `onSubmit` prop exists in the contract but no wiring to a real endpoint was found; `state` can be forced to `idle/loading/success/error` for documentation purposes only. | |

## Summary

Every interaction that *looks* functional in the prototype is client-only and explicitly labeled as a preview wherever a real order/account/promotion would otherwise be implied. The one exception with genuine (if local-only) persistence is the guest wishlist. This is a disciplined prototype — it does not fabricate server behavior — which significantly de-risks the conversion: there is no "fake backend logic" to unlearn, only UI/interaction patterns to reproduce and wire to real WooCommerce/WordPress endpoints.
